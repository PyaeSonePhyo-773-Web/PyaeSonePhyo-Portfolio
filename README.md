# Pyae Sone Phyo — Cloud & DevOps Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally

1. Extract the ZIP.
2. Open `index.html` in your browser.

For a local development server, you can use VS Code Live Server or:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

- Update the profile copy and project cards in `index.html`.
- Adjust colors, layout and responsive styles in `css/style.css`.
- Change the GitHub username in `js/main.js` if your account changes.
- The live GitHub section requests public repositories from the GitHub REST API. Curated project cards remain visible if the API is unavailable.

## Deploy with GitHub Pages

1. Create a repository named `portfolio` (or `<username>.github.io`).
2. Upload the extracted files to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.

## Notes

This portfolio intentionally avoids publishing personal contact details, home address, phone number or date of birth. Skills are described as hands-on, project use, learning or future plans rather than overstated proficiency.


## EN / 日本語
A language switcher is included in the navigation. It translates navigation labels, the hero role and key section labels. Expand `portfolioTranslations` in `js/main.js` to translate additional content.
